# Парсер цен на товары (вариант 2, Азамат Комаев)

Это Spring Boot приложение, которое ходит по ссылкам на товары и вытаскивает оттуда название, краткое описание, цену и дату публикации. Всё складывается в H2, а забрать результат можно через обычный REST.

В качестве основного сайта я взял labirint.ru: это настоящий магазин, и при этом он не прячется за защитой от скрапинга, так что парсер работает без обходных решений. Для надёжности добавлены ещё два простых источника, чтобы проверка не зависела от одного сайта.

| Домен | Как читаем | Что важно знать |
|---|---|---|
| labirint.ru | HTML через Jsoup | основной источник; точной даты на странице нет, поэтому берём год издания |
| books.toscrape.com | HTML через Jsoup | учебный магазин для тренировки парсинга; даты публикации нет |
| dummyjson.com | JSON через WebClient | тестовое API, тут дата есть |

Нужный парсер приложение выбирает само по домену ссылки.

## Как запустить

Понадобится JDK 21. Именно JDK, с компилятором `javac`: одного JRE не хватит. Gradle ставить не нужно, он подтянется сам.

```
./gradlew bootRun
```

Через несколько секунд приложение поднимется на http://localhost:8080. Чтобы не начинать с пустой базы, при старте оно само загрузит три ссылки, по одной на каждый источник. Этот список можно поменять в `application.properties`, параметр `app.seed.urls`.

Если в системе несколько JDK, нужный можно указать явно:

```
JAVA_HOME=/путь/к/jdk ./gradlew bootRun
```

## Как проверить

1. Откройте http://localhost:8080/answer. Там уже должны лежать товары, загруженные при старте.

2. Отправьте свои ссылки на парсинг:

```
curl -X POST http://localhost:8080/api/parse \
  -H "Content-Type: application/json" \
  -d '{"urls":["https://www.labirint.ru/books/1007504/","https://books.toscrape.com/catalogue/tipping-the-velvet_999/index.html","https://dummyjson.com/products/2"]}'
```

   Ответ придёт сразу (код 202) вместе с `id` задачи, а сам парсинг пойдёт в фоне.

3. Посмотрите, как дела у задачи: `GET http://localhost:8080/api/jobs/{id}`. Статус будет `RUNNING`, потом `DONE` или `DONE_WITH_ERRORS`. Если какая-то ссылка не отработала, причина будет в поле `errors`.

4. Заберите результаты: `GET http://localhost:8080/answer`. Можно настроить выдачу параметрами:

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `page` | 0 | номер страницы |
| `size` | 20 | сколько товаров на странице (от 1 до 200) |
| `sort` | id | по какому полю сортировать: `id`, `title`, `price`, `parsedAt`, `source` |
| `dir` | asc | направление: `asc` или `desc` |
| `q` | не задан | поиск по части названия |
| `minPrice`, `maxPrice` | не заданы | границы цены |

   Например, пять самых дорогих товаров дороже 10: http://localhost:8080/answer?sort=price&dir=desc&minPrice=10&size=5

5. История цен конкретного товара: `GET http://localhost:8080/api/products/{id}/history`. Каждый новый парсинг добавляет туда запись.

6. Если хочется заглянуть в базу напрямую, есть консоль H2: http://localhost:8080/h2-console. JDBC URL `jdbc:h2:file:./data/prices`, пользователь `sa`, пароль пустой.

## Что внутри

- **Пул потоков.** Свой `ThreadPoolExecutor` в `AppConfig`, размеры настраиваются в `app.pool.*`. Каждая ссылка - отдельная задача через `CompletableFuture`.
- **Вежливость к сайтам.** На один хост одновременно идёт не больше `app.fetch.host-parallelism` запросов (за этим следит семафор), и после каждого запроса есть небольшая пауза `app.fetch.delay-ms`.
- **Потокобезопасность.** Задачи и семафоры лежат в `ConcurrentHashMap`. Одну и ту же ссылку нельзя обработать дважды одновременно: за этим следит множество из `ConcurrentHashMap.newKeySet()`. Счётчики в статусе задачи - `AtomicInteger`, список ошибок - `ConcurrentLinkedQueue`.
- **Расписание.** `RefreshScheduler` на `@Scheduled` каждые 10 минут заново парсит все сохранённые товары и дописывает новую цену в историю. Интервал меняется в `app.refresh.*`.
- **Выдача результатов.** `/answer` читает данные из H2 и фильтрует с сортировкой через `parallelStream()` (`ProductQueryService`).
- **HTTP-клиент.** `WebClient` из WebFlux.
- **Хранилище.** Файловая H2 в папке `data/`. Хотите начать с чистого листа - просто удалите эту папку.

## На что обратить внимание

Labirint не защищается от ботов, но если слать запросы слишком часто, он всё равно может начать отвечать ошибками. Именно поэтому в приложении есть лимиты на хост. Если один сайт недоступен, остальные ссылки это не ломает: ошибка просто попадёт в `errors` своей задачи.
